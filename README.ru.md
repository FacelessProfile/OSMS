# Основы систем мобильной связи (ОСМС) - Практикум и РГР

[🇷🇺 Русский](README.ru.md) | [🇬🇧 Read in English](README.md)

[![License: MIT](https://img.shields.io/badge/Лицензия-MIT-blue.svg)](LICENSE)
[![MATLAB Compatibility](https://img.shields.io/badge/MATLAB-R2019b%2B-orange.svg)](https://www.mathworks.com/products/matlab.html)

Репозиторий содержит практические задания и расчётно-графическую работу (РГР) по курсу **«Основы систем мобильной связи» (ОСМС)**.

Проект поддерживает **двуязычную структуру (Dual Track)**, обеспечивая удобство как для сдачи работ в университете, так и для демонстрации чистого инженерного кода:

* **`labs_ru/`** - скрипты для сдачи: с сохранением номеров заданий, вариантов, русскоязычных комментариев и локальных вспомогательных функций.
* **`labs_en/`** - рефакторинг по международным стандартам: чистый инженерный код, англоязычные идентификаторы, математические пояснения и строгие соглашения об именовании.

Каждая работа представляет собой **один полностью самодостаточный `.m` файл**, не требующий настройки путей (`addpath`) или установки сторонних тулбоксов.

## Запуск кода

Для запуска любой работы откройте файл в MATLAB и нажмите клавишу **F5** (или вызовите команду `run`):

```matlab
% Запуск Практической работы №1
run('labs_ru/lab01.m');
% Или
run('labs_en/lab01_sampling_and_fourier.m');
```

Внутри каждого скрипта реализована программная генерация необходимых сигналов, поэтому код запускается автономно без внешних файлов и зависимостей.
