Репозиторий содержит практические задания и расчётно-графическую работу (РГР) по курсу **«Основы систем мобильной связи» (ОСМС)** (СибГУТИ).

Структура проекта сочетает **двуязычные треки (`labs_ru/`, `labs_en/`)** и отдельные каталоги по работам с подробными описаниями:
* **`labs_ru/`** и **`labs_en/`** - автономные MATLAB/Octave-скрипты для сдачи в университете и в международном оформлении (`lab01.m` / `lab01_sampling_and_fourier.m`).
* **`lab1/`, `lab2/`, `lab4/`, `lab5/`, `RGR/`** - двуязычные описания (`README.ru.md` / `README.md`), а также исходный код на MATLAB, C++ и MEX (`lab4/lab4.m`, `lab4/gold.cpp`, `lab5/crc.cpp`, `lab5/crc_mex.cpp`, `lab5/plot_crc_delay.m`, `RGR/rgr.m`).

## Запуск кода

Для запуска MATLAB/Octave-скриптов или компиляции C++-программ из корня репозитория:

```matlab
% Запуск Практической работы №1
run('labs_ru/lab01.m');
% Или
run('labs_en/lab01_sampling_and_fourier.m');

% Запуск Практической работы №4
run('lab4/lab4.m');

% Запуск Практической работы №5 (бенчмарк задержки MATLAB + MEX)
cd('lab5'); run('plot_crc_delay.m');

% Запуск РГР
cd('RGR'); run('rgr.m');
```

```bash
# Сборка и запуск генератора последовательностей Голда (ЛР №4, C++)
g++ -O2 lab4/gold.cpp -o gold
./gold
./gold 0001100001001100010010101000000

# Сборка и запуск проверки CRC (ЛР №5, C++)
g++ -O2 lab5/crc.cpp -o lab5/crc
./lab5/crc
```

Внутри скриптов реализована программная генерация необходимых сигналов и последовательностей, поэтому код запускается автономно без внешних файлов.
