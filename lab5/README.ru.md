# Лабораторная работа №5. Циклический избыточный код (CRC)

**Вариант:** 25 (`G(x) = x^7 + x^3 + x^2 + x + 1`, `10001111`, длина CRC `7` бит)

Реализация вычисления и проверки CRC на C++ (двоичное деление с XOR), тест поочерёдного искажения каждого бита, проверка обнаружения ошибок в канале AWGN и бенчмарк времени вычисления CRC в MATLAB через прямой вызов C++-функций (MEX).

## Исходные данные

- Порождающий полином: `G = 10001111` (`n = 8` бит, длина CRC `M = 7` бит)
- Короткий пакет (п. 1–3): `N = 20 + 25 = 45` бит (`52` бита с CRC)
- Длинный пакет (п. 4–5): `N = 250` бит (`257` бит с CRC)
- Тест в канале AWGN: `sigma = 0.5`
- Бенчмарк задержки (MATLAB + MEX): длина CRC `1..32` бит, размеры пакетов `250 B` (`2000` бит) и `1000 B` (`8000` бит), `10000` прогонов на точку (среднее геометрическое)

## Основные результаты

- При передаче без искажений для `N = 45` и `N = 250` бит остаток на приёмнике равен `0000000` (ошибок нет).
- В цикле поочерёдного искажения каждого из `257` бит обнаружено **257 из 257 ошибок**, пропущено **0** (100% обнаружение одиночных ошибок).
- В канале с шумом AWGN (`sigma = 0.5`) произошло 8 битовых искажений, остаток `1011000` — ошибка корректно зафиксирована.
- Бенчмарк через MATLAB MEX подтвердил линейный рост задержки обработки `O(N * L_CRC)`: от `~15` до `~43` мкс для пакета `250 B` и от `~50` до `~162` мкс для пакета `1000 B` (пропорциональный рост в ~4 раза).

## Файлы

- [`crc.cpp`](crc.cpp) - программа на C++ для расчёта и проверки CRC, теста 257 одиночных искажений и проверки в канале AWGN
- [`crc_mex.cpp`](crc_mex.cpp) - MEX-обёртка для прямого вызова `generateData` и `calcCRC` из `crc.cpp` в MATLAB
- [`plot_crc_delay.m`](plot_crc_delay.m) - скрипт MATLAB для компиляции `crc_mex.cpp`, замера среднего геометрического времени обработки по 10000 прогонам и построения графика `crc_delay.png`

## Запуск

```bash
g++ -O2 crc.cpp -o crc
./crc
```

В MATLAB (из папки `lab5/`):

```matlab
run('plot_crc_delay.m')
```
