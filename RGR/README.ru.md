# Расчётно-графическая работа (РГР). Сквозная модель тракта передачи данных в MATLAB

**Вариант:** 25 (код Голда из ЛР №4 + полином CRC-7 из ЛР №5)

Полная модель цифрового тракта передачи и приёма сообщений в MATLAB: ASCII-кодирование/декодирование, контроль ошибок CRC-7, кадровая синхронизация по 31-битной последовательности Голда, амплитудная модуляция (`N` отсчётов на бит), случайный сдвиг пакета, канал с шумом AWGN, корреляционный приёмник, пороговый демодулятор, спектральный анализ (БПФ) и моделирование Монте-Карло с `parfor` (зависимость `BLER`, `BER` и корреляционного пика от `sigma`).

## Исходные данные

- Передаваемое сообщение: `Nikita Shalamov` (`15` символов ASCII -> `L = 120` бит)
- Полином CRC-7 (ЛР №5, вар. 25): `poly = [1 0 0 0 1 1 1 1]`, `M = 7` бит (`CRC = 0101100`)
- Преамбула синхронизации (ЛР №4, вар. 25): `31`-битный код Голда (`x1 = 25`, `y1 = 1`, `G = 31` бит)
- Полная длина кадра: `G + L + M = 158` бит
- Отсчётов на бит: `N = 8` (для спектров также `N = 4` и `N = 16`, для сравнения `BLER`/`BER` также `N = 2`)
- Частота дискретизации: `fs = 1000` Гц

## Основные результаты

- При сдвиге `shift = 420` и `sigma = 0.25` корреляционный приёмник (`find_sync` с центрированным эталоном Голда) точно определяет начало кадра на отсчёте `421`, пороговый демодулятор (`P = N/2 = 4`) безошибочно восстанавливает биты, остаток CRC равен `0000000`, строка `Nikita Shalamov` декодируется без искажений.
- При `sigma = 0.50` синхронизация сохраняется (отсчёт `421`), а проверка CRC надёжно фиксирует возникшие ошибки.
- Спектральный анализ подтверждает равномерный спектр шума AWGN и обратную зависимость ширины главного лепестка от длительности символа (`±250 Гц` при `N = 4`, `±125 Гц` при `N = 8`, `±62.5 Гц` при `N = 16`).
- Моделирование Монте-Карло (`5000` прогонов на точку, `parfor`) для `N = 8` и `N = 2` показывает сдвиг кривой `BLER` влево ровно в 2 раза (`BLER = 0.5` при `sigma ≈ 0.27` против `0.55`), что соответствует теоретическому выигрышу накопления `sqrt(8/2) = 2`.
