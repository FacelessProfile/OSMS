# Лабораторная работа №4. Изучение корреляционных свойств последовательностей синхронизации

**Вариант:** 25 (нечётный номер группы - схема 4.5)

Генерация последовательностей Голда на C++ и MATLAB, сравнение циклической и апериодической АКФ, расчёт взаимной корреляции и программная проверка критериев баланса, цикличности и корреляции (постулаты Голомба)

## Исходные данные

- Период последовательности: `N = 2^5 - 1 = 31` (разрядность регистров `m = 5`)
- Первая последовательность (`seq1`): `x1 = 25` (`11001`), `y1 = 1` (`00001`)
- Вторая последовательность (`seq2`): `x2 = 26`, `y2 = 27`

## Основные результаты

- Циклическая АКФ `seq1` даёт пик `R(0) = 1.00` и три уровня боковых лепестков: `{-0.03, 0.10, 0.23}`.
- Взаимная корреляция при нулевом сдвиге между `seq1` и `seq2`: `R_12 = -0.10`.
- Показано отличие циклической бинарной АКФ от функций `autocorr()` и биполярной `xcorr(..., 'normalized')`: без циклического переноса при росте сдвига уменьшается область перекрытия, из-за чего амплитуда лепестков затухает к нулю.
- В обеих реализациях добавлена функция `autocheck` для проверки трёх постулатов Голомба (баланс единиц и нулей, серии длин, свойство автокорреляции).

## Файлы

- [`gold.cpp`](gold.cpp) - программа на C++ для генерации, вывода таблицы циклической АКФ, `R_12` и проверки `autocheck` (принимает произвольную битовую строку в качестве аргумента CLI)
- [`lab4.m`](lab4.m) - скрипт MATLAB для сравнения циклической АКФ, уровня `-1/N` М-последовательности и `autocorr()` с построением графиков

## Запуск

```bash
g++ -O2 gold.cpp -o gold
./gold
./gold 0001100001001100010010101000000
```

В MATLAB:

```matlab
run('lab4.m')
```
